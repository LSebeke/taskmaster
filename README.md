# Taskmaster

Gantt-first project management for a solo engineer, planned as an Obsidian plugin. Tracks hours against plan, forecasts finish dates from your real capacity, finds the critical chain, and tells you when to cut scope.

Status: spec and prototype. The plugin is not built yet.

- [`SPEC.md`](SPEC.md): implementation spec, ready to hand to an agent.
- [`prototype/taskmaster-prototype.html`](prototype/taskmaster-prototype.html): throwaway interactive prototype with fake data. Download it and open it in a browser. The Scenarios tab has guided walkthroughs.
